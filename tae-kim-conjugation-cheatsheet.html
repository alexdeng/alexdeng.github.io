Master tense matrix — all tenses, all word types

Japanese has exactly two tenses: non-past (present & future — context and time words decide) and past. Cross them with affirmative / negative and plain / polite and you get the whole system, for every word type, in one grid. Rows are in the same order as every other tense table on this page.

How to read: pick the row (tense × plain/polite), then the column (word type). Example — past negative, polite, verb: 飲みませんでした.

B · Verb paradigms

Contents ↑

Verbs — plain forms at a glance

The core 4: dictionary, negative, past, past-negative. Everything else (て, たら, たい) is built from these stems.

る-verb (ichidan): drop る + ending.   う-verb (godan): final kana shifts row — あ-row for negative, い-row for stem, た/て with sound changes (next table).
Formる-verb — 食べるう-verb — 飲むう-verb — 話す
Non-pastdictionary form食たべるtaberu飲のむnomu話はなすhanasu
Non-past Neg.～ない食たべないtabenai飲のまないnomanai話はなさないhanasanai
Past～た / ～だ食たべたtabeta飲のんだnonda話はなしたhanashita
Past-Neg.～なかった食たべなかったtabenakatta飲のまなかったnomanakatta話はなさなかったhanasanakatta
て-form食たべてtabete飲のんでnonde話はなしてhanashite

⚠ Irregulars — memorize as-is

  • する suru → しない / した / して
  • 来る kuru → こない / きた / きて
  • ある aru → negative is just ない (no あらない)
  • 行く iku → 行って / 行った (not 行いて)

The う → わ trap

う-verbs ending in う go to わ, not あ, in the negative: 買う → 買わない kawanai, 会う → 会わない awanai. Every other う-verb uses the plain あ-row.

て-form & た-form — う-verb sound changes

For る-verbs it’s trivial (drop る + て / た). For う-verbs, the ending collapses — group by final kana. た-form is identical, just swap て→た, で→だ.

Dictionary endingて-formExampleた-form
う ・ つ ・ る～って-tte買う→買ってkau → katte · 立つ→立って · 帰る→帰って～ったkatta / tatta / kaetta
む ・ ぶ ・ ぬ～んで-nde飲む→飲んで · 遊ぶ→遊んで · 死ぬ→死んで～んだnonda / asonda / shinda
く～いて-ite書く→書いてkaku → kaite～いたkaita
ぐ～いで-ide泳ぐ→泳いでoyogu → oyoide～いだoyoida
す～して-shite話す→話してhanasu → hanashite～したhanashita

Mnemonic in one line: うつる → って, むぶぬ → んで, く → いて, ぐ → いで, す → して. If you can say the て-form, you already know the た-form, たら and たり — they all share the same stem.

Desire — ～たい “want to do”

Stem + たい. The result conjugates exactly like an い-adjective.

Form食べたい飲みたい
Non-past食べたいtabetai飲みたいnomitai
Non-past Neg.食べたくないtabetakunai飲みたくないnomitakunai
Past食べたかったtabetakatta飲みたかったnomitakatta
Past-Neg.食べたくなかったtabetakunakatta飲みたくなかったnomitakunakatta

For things (not actions): use ～が欲しい hoshii — also an い-adjective: 欲しい / 欲しくない / 欲しかった / 欲しくなかった.

C · Adjectives & state-of-being

い-adjectives, な-adjectives, nouns — and the explanatory のだ built on them.

Contents ↑

い-Adjectives — 高い

い-adjectives conjugate by themselves — no だ needed. Drop final い and attach. The one irregular is いい (from よい).

Form高い — expensive / tallRuleいい — good (irregular)
Non-past高いtakaidictionaryいいii
Non-past Neg.高くないtakakunai～く + ないよくないyokunai
Past高かったtakakatta～かったよかったyokatta
Past-Neg.高くなかったtakakunakatta～く + なかったよくなかったyokunakatta
て-form高くてtakakute～くて — for linkingよくてyokute
Adverb高くtakaku～く + verbよくyoku

Polite: just add です without changing the adjective — 高いです / 高かったです. Never *高いだ.

な-Adjectives & Nouns — だ / です

These don’t conjugate themselves; the copula does. That’s why their table looks exactly like the left column of the んだ table.

FormPlain — 静か / 学生Polite
Non-past静かだ / 学生だshizuka da / gakusei da静かです / 学生ですshizuka desu / gakusei desu
Non-past Neg.静かじゃない / 学生じゃないshizuka ja nai / gakusei ja nai静かじゃないです / 静かではありませんja nai desu / dewa arimasen
Past静かだった / 学生だったshizuka datta / gakusei datta静かでした / 学生でしたshizuka deshita / gakusei deshita
Past-Neg.静かじゃなかった / 学生じゃなかったshizuka ja nakatta / gakusei ja nakatta静かじゃありませんでしたja arimasen deshita
て-form静かで / 学生でshizuka de / gakusei deUse で to link clauses

Attaching to a noun: な-adj + な + noun (静かな部屋), noun + の + noun (学生の本). That な is the same な you saw in 学生なんだ — wait, no: nouns take な before んだ in the explanatory form, even though plain noun + noun uses の.

「んだ」 — explanatory tone

Adds an explanatory / “it is that…” nuance. Short form of のだ. To conjugate it, inflect what comes before んだ — substitute の for ん and のだ for んだ when you need the full form.

Pattern: Noun / な-adj needs な before んだ → 学生なんだ. Verbs & い-adj attach directly → 飲むんだ / 高いんだ.
FormNoun / Na-Adj — 学生Verb / I-Adj — 飲むMeaning cue
Non-past学生がくせいなんだgakusei nan da飲のむんだnomun daIt’s that (I’m) a student / (I) drink
Non-past Neg.学生がくせいなんじゃないgakusei nan ja nai飲のむんじゃないnomun ja naiIt’s not that…
Past学生がくせいなんだったgakusei nan datta飲のむんだったnomun dattaIt was that…
Past-Neg.学生がくせいなんじゃなかったgakusei nan ja nakatta飲のむんじゃなかったnomun ja nakattaIt wasn’t that…

Polite version: んです n desu — e.g. 飲むんです, 学生なんです. In questions you’ll hear んですか？ constantly: it asks for an explanation, not just yes/no.

D · Aspect

Ongoing, resulting, experienced and completed actions.

Contents ↑

Aspect — ～ている in every tense

て-form + いる. いる itself conjugates like a る-verb, so tense and negation all live on いる — same row order as the master matrix. Three readings: action in progress (“is drinking”), resulting state (“is married / lives / is wearing”), and habitual (“drinks every day / works at…”).

Tense食べる → 食べている飲む → 飲んでいる
Non-past食たべているtabete iru飲のんでいるnonde iru
Non-past Neg.食たべていないtabete inai飲のんでいないnonde inai
Past食たべていたtabete ita飲のんでいたnonde ita
Past-Neg.食たべていなかったtabete inakatta飲のんでいなかったnonde inakatta
Non-pastpolite食たべていますtabete imasu飲のんでいますnonde imasu
Non-past Neg.polite食たべていませんtabete imasen飲のんでいませんnonde imasen
Pastpolite食たべていましたtabete imashita飲のんでいましたnonde imashita
Past-Neg.polite食たべていませんでしたtabete imasen deshita飲のんでいませんでしたnonde imasen deshita

Speech contraction: いる is usually dropped to just る — 食べてる / 飲んでる tabeteru / nonderu.

～てある te aru — done & ready

Result of an intentional action, still in effect: 予約してある “(I) have it reserved.” Object takes が. Past: ～てあった.

～ておく te oku — do in advance

Preparation for later: 買っておく “buy ahead of time.” Contracts to ～とく / ～どく (買っとく, 飲んどく). Past: ～ておいた.

～てみる te miru — try doing

食べてみる “try eating (and see).” Conjugates on みる.

～ていく / ～てくる — change over time

増えていく “keep increasing (from now)”; 増えてきた “has increased (up to now).”

Experience, listing & completion

Three past-stem patterns: having done something before, listing sample actions, and finishing (or regretting) an action. All are built on the た-form, so tense sits on the final word.

～たことがある — “have done … before.” ある conjugates like any existence verb; the negative ことがない means “have never done …”.
Tense食べる飲むMeaning
Non-past食たべたことがあるtabeta koto ga aru飲のんだことがあるnonda koto ga aruhave eaten / drunk before
Non-past Neg.食たべたことがないtabeta koto ga nai飲のんだことがないnonda koto ga naihave never eaten / drunk
Past食たべたことがあったtabeta koto ga atta飲のんだことがあったnonda koto ga attahad (at some point) …
Past-Neg.食たべたことがなかったtabeta koto ga nakatta飲のんだことがなかったnonda koto ga nakattahad never …

～たり tari — listing sample actions

た-form + り, repeat, close with する (which carries the tense): 食べたり飲んだりする “do things like eat and drink.” Past: 食べたり飲んだりした.

～てしまう te shimau — completion / regret

食べてしまう tabete shimau · past 食べてしまった · neg 食べてしまわない. Contracts in speech to ～ちゃう / ～じゃう: 食べちゃった, 飲んじゃった.

Conditionals — たら / ば / なら / と

Four ways to say “if / when.” たら is the most general; ば is hypothetical; なら is contextual (“if it’s the case that…”); と is for automatic / inevitable results.

Word type～たら～ば～なら
Verb食べたら / 飲んだらtabetara / nondarapast + ら食べれば / 飲めばtabereba / nomebaえ-row + ば食べるなら / 飲むならtaberu nara / nomu nara
い-adj高かったらtakakattara高ければtakakerebadrop い + ければ高いならtakai nara
な-adj / Noun静かだったら / 学生だったらshizuka dattara— use なら or であれば静かなら / 学生ならshizuka nara / gakusei nara
Negative ば食べなければ / 飲まなければ / 高くなければ tabenakereba / nomanakereba / takakunakereba — pattern: negative stem + ければ (“if not…” / “must” with ならない)

Volitional — ～よう “let’s / I shall”

Plain counterpart of ましょう. Also used after と思う for intentions.

TypeRuleExample
る-verbdrop る + よう食べる → 食べようtaberu → tabeyou
う-verbう-row → お-row + う飲む → 飲もうnomu → nomou · 行く → 行こう
Irregularmemorizeする → しよう · 来る → 来よう suru → shiyou · kuru → koyou

Potential — can do

Result behaves like a る-verb, whatever the original verb was. Object often marked with が instead of を.

TypeRuleExample → Negative / Past
る-verbdrop る + られる食べられるtaberareru → 食べられない / 食べられた
う-verbう-row → え-row + る飲めるnomeru → 飲めない / 飲めた · 話せる hanaseru
Irregularmemorizeする → できる dekiru · 来る → 来られる korareru

Spoken shortcut: ら is often dropped for る-verbs in speech — 食べれる tabereru. Understand it, but use the full 食べられる in careful writing / exams.

Passive & Causative — quick map

Both are built from the negative stem region — if you know the ない-form stem, you’re one step away.

る-verb — 食べるう-verb — 飲むRule
Passivebe done to食べられるtaberareru飲まれるnomareruる: +られる · う: あ-row + れる
Causativemake / let食べさせるtabesaseru飲ませるnomaseruる: +させる · う: あ-row + せる
Causative-Passive食べさせられるtabesaserareru飲まされるnomasareruう-verbs shorten to ～される
Irregularsする → される / させる · 来る → 来られる / 来させる suru → sareru / saseru · kuru → korareru / kosaseru

Watch out: for る-verbs, potential and passive are both ～られる (食べられる = can eat / be eaten). Context and particles (が vs に) disambiguate.

Polite — ます forms

Use the stem (る-verb: drop る; う-verb: い-row) + ます paradigm. The past and negative live entirely in the ending.

る-verb — 食べるう-verb — 飲むEnding
Non-pastpresent / future食べますtabemasu飲みますnomimasu～ます
Non-past Neg.食べませんtabemasen飲みませんnomimasen～ません
Past食べましたtabemashita飲みましたnomimashita～ました
Past-Neg.食べませんでしたtabemasen deshita飲みませんでしたnomimasen deshita～ませんでした
Volitional (polite)食べましょうtabemashou飲みましょうnomimashou～ましょう = let’s…

Honorific & humble verbs — 敬語

Raise the other person’s actions (honorific), lower your own (humble). The common verbs have special forms — memorize this table; everything else uses the productive patterns below.

MeaningPlainHonorificHumble
go / come / be行く・来る・いるiku · kuru · iruいらっしゃるirassharu参る / おるmairu / oru
say言うiuおっしゃるossharu申す・申し上げるmousu · moushiageru
doするsuruなさるnasaruいたすitasu

Productive honorific pattern

お + stem + になる: お読みになる “(you) read.” The passive form ～られる is also used as a lighter honorific: 読まれる.

Productive humble pattern

お + stem + する: お持ちする “I’ll carry it (for you).” Sino-Japanese verbs take ご: ご案内する.

Conjugation: special verbs inflect as う-verbs (いらっしゃる → いらっしゃらない / いらっしゃった; note ます-form いらっしゃいます). くださる → くださいます.

Formal and literary forms for reading and essays.

Contents ↑

Written / formal style — である

Essays, articles and reports drop ます/です and use plain forms, with the copula written である and a literary negative ぬ. Same tense rows as everywhere else on this page.

TenseCopula — noun / な-adjVerb — literary negative
Non-past学生がくせいであるgakusei de aruuse the plain form: 飲む / 食べる
Non-past Neg.学生がくせいではないgakusei de wa nai飲のまぬ / 食たべぬnomanu / tabenu — negative stem + ぬ (literary ない)
Past学生がくせいであったgakusei de attause the plain past: 飲んだ / 食べた
Past-Neg.学生がくせいではなかったgakusei de wa nakatta～なかった, as in speech
Without doing～ずに—食たべずに / 飲のまずにtabezu ni / nomazu ni — negative stem + ず. Irregular: する → せず, 来る → こず

Also in writing: だ is kept in casual written style (headlines, narration, notes); である is the formal essay register. ぬ never takes tense itself — past is still ～なかった.
